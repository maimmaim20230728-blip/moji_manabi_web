このアプリの書き順データ(data/kanji.js)は、KanjiVG プロジェクトの kanji/ の SVG をもとに作ったものです(取得 2026-09-28〜29・node data_src/_fetch_kanjivg.js)。
The stroke order data in this app (data/kanji.js) is derived from the SVG files in the KanjiVG project (kanji/ directory), fetched on 2026-09-28/29.

data/kanji.js は、これらの SVG の <path d> を書き順のとおりに並べ直し、字と読みを添えたものです。
data/kanji.js contains the path d attributes of these SVG files in stroke order, together with each character and its readings.
