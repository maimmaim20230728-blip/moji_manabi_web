# 書き順のおさらい・そよぎ (Web版)

漢字の書き順のなぞりと読み上げを、点数も失敗音も出さずに。今日の分だけ。端末内のみ・オフライン・登録なし。

- 版: 0.5.4(Play版と同じ中身)
- 無料・広告なし・登録なし。書いたことはこの端末の中だけに保存され、どこにも送られません
- 12言語(日本語・English・Deutsch・Français・Español・Italiano・Português・Nederlands・Svenska・한국어・中文・العربية)
- 書き順データ: KanjiVG(Ulrich Apel 作・CC BY-SA 3.0) https://kanjivg.tagaini.net/
- KanjiVG をもとに作った data/kanji.js も CC BY-SA 3.0 です(ライセンスの全文は data/LICENSE-KanjiVG.txt)
- このフォルダは本体(非公開)から `node _sync_web.js` で作り直しています。ここを直接直さないでください
- 提供: 介護と支援の相談どころ「そよぎ」 https://soudansoyogi.com/
